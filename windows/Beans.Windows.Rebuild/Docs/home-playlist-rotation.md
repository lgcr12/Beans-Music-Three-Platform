# 首页推荐歌单换批

首页“推荐歌单”新增“换一批”，使用本次已加载的真实公开推荐与歌单广场数据，不发起网络请求。候选以平台和歌单标识共同去重，保留来源与详情路由。

- 初次展示沿用平台交替排列；后续优先选择未展示的候选，并避开当前四张卡片。
- 所有候选展示后开始下一轮。记录仅保留在当前应用会话。
- 候选不足以替换全部卡片时保留部分当前内容并显示说明；无额外候选时提示使用首页“刷新”。
- “刷新”仍请求平台最新内容并重建候选列表，不保证平台每次返回不同推荐。
- 不将公开歌单轮换描述为个性化推荐。

验证：Debug 测试构建、Release 构建和差异格式检查通过，400 项测试通过（新增连续轮换不联网、候选不足、单平台可用三个回归用例）。界面截图与实际点击验收未执行。

## 顶部横幅轮播

顶部横幅改为最多四张真实内容：优先选取各平台可打开的 Hero，再从公开歌单候选补充，按路由、平台及内容标识去重。图片、标题、平台说明与跳转目标一起切换。榜单使用现有 `ranking-detail` 路由。

首页可见时每 7 秒轮播；鼠标悬停、键盘焦点位于横幅、刷新中或用户点击“暂停轮播”时不自动切换。关闭 Windows 动画时停止自动切换，仍允许点击圆点手动选择。离开首页停止计时，返回恢复订阅。圆点数量反映真实候选数量，零张或一张时不显示轮播控件。

Debug、Release 构建、差异格式检查与 403 项测试通过，覆盖横幅标题/图片/目标一致、循环回绕、不请求网络、空候选与单候选。定时切换、悬停及页面返回的实际 UI 验收尚未执行。
