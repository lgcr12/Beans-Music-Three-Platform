# Beans 歌单持久化修复（2026-09-27）

## 问题与处理

- 旧服务将 JSON、IO 和权限读取错误当成空列表返回，页面又在读取前清空列表，导致读取异常表现为歌单消失；随后创建歌单还可能覆盖原数据。
- 读取失败现在向页面报告错误，保留已经显示的歌单；音乐库和 Beans 歌单分别显示状态，避免并行加载覆盖错误提示。
- 用文件锁保护完整的读取、修改、保存事务，覆盖多个服务实例/进程；写入使用唯一临时文件、磁盘刷新和原子替换。
- 保存保留上一版 .bak，主文件缺失或损坏时读取有效备份；没有有效备份时拒绝覆盖损坏数据。恢复后的下一次保存保留损坏原件。

- Release 构建通过；现有及新增测试共 458 项通过，0 失败。
- 新增 6 项持久化测试覆盖并发创建、损坏文件拒绝覆盖、备份恢复、数据文件占用、等待锁时取消和主文件缺失。
- 启动新版本，在“我的音乐”和“我的歌单”均确认 mix / 232 首；返回和刷新后仍显示。
- 原歌单 JSON 校验值保持不变，1 个歌单、232 首歌曲；未通过真实用户数据执行写入测试。
