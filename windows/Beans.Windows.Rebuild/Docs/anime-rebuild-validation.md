# 日漫专区重构与视觉验收

更新日期：2026-09-26。实现位于 Windows Rebuild，参考 image-3742 至 image-3749。

## 实现

- 独立 AnimeShell 使用同一窗口和播放服务；首页、索引、搜索、详情、收藏及歌词视图共享底部播放器。
- 浅色面板使用原生 AcrylicBrush、细描边和统一圆角；深色详情使用透色面板、紫色主按钮、紧凑曲目表。歌单弹窗使用圆形选择控件和固定底部操作区。
- 索引页的滚动内容强制拉伸到窗口宽度，筛选后不会出现面板向右收窄；番剧卡片整卡可点击进入专题。首页搜索框扩大到可容纳长标题。
- 搜索页和索引页请求 Bangumi `/v0/search/subjects`；命中本地精选也继续查询其他版本，并保留精选条目的歌曲映射 ID。网络失败、真正的空结果和旧缓存分别显示状态。
- 未输入关键词时直接读取 Bangumi `/calendar` 中的海报与 `air_date`，不再额外请求每一部详情。内置 2026-09-26 抓取的 111 条日历资料，进入索引即显示快照并联网更新；日历缓存 6 小时，断网保留旧缓存或内置快照。
- 年份下拉包含 1960 年至明年，使用服务端 `air_date` 起止条件；题材使用 `tag`，每页 20 条并支持加载更多。查询缓存 1 天，按关键词、年份、题材和偏移隔离；输入防抖 350ms，取消过时请求。排序作用于已加载条目。
- 系列卡片保留每个版本；按完整中日文标题和明确季度/剧场版标记聚合，搜索再补充官方动画关联关系，不按标题前四字或搜索词强行合并。展开页按首播排序并补充直接关联动画；忽略小说、音乐、游戏及仅“相同世界观”的关系，关联缓存 7 天。每个版本可进入详情并返回系列。
- 首页当前使用由参考截图修补得到的宽幅海岸素材，仍存在拼接和界面残留，不能视为干净背景的最终验收结果。未成功调用图像生成；此前获准的 CLI/API 生成方式因缺少本机密钥未执行。
- 进入/返回使用 360ms 柔和光带和淡入位移过渡，去除黑幕裂纹效果，支持减少动效。播放、队列、歌词调用现有服务。
- 六部精选作品支持中日文和罗马音检索；QQ、网易云独立匹配标题、作者和版本。芙莉莲第一季收录《勇者》《Anytime Anywhere》和特别篇《bliss》，孤独摇滚补充 OP、ED 和三首插曲。TV Size、现场及伴奏录音独立展示，预览数据不作为真实匹配。
- 元数据缓存七天、录音匹配缓存三天，失败可使用旧缓存。缓存不保存播放地址。收藏、歌词字号/行距/翻译/减少动效单独持久化。
- Beans 歌单支持选曲、选择多个歌单、创建和按平台歌曲 ID 去重；部分保存失败后重试复用已创建歌单。

## 验收边界

- 番剧目录支持 Bangumi 在线查询；精选与轻音系列使用内置曲目关系，其他作品尝试读取 Bangumi 的音乐关联。缺少关联时仍可能没有曲目，平台未匹配时保留曲目及待匹配状态。关联专辑标题不一定等于其中每首歌名，合辑解析仍有边界。
- 系列扩展查询已显示版本的直接关联，单次最多补充 60 部；不声称穷尽大型系列。无官方关联时采用保守标题规则，无法确认的条目保留独立。
- 海报与插画素材不同于参考图，不声称逐像素一致。实际海报保持作品对应关系。
- 未找到已验证的作品级正版播放页时隐藏“观看番剧”，保留 Bangumi 和动画官网；不使用平台首页冒充观看链接。
- 平台录音匹配成功不代表账号拥有播放权限，播放时由现有播放器验证。
- 本轮更新标准 `bin/Release` 与 `bin/Debug`；`Start-BeansMusic.cmd` 默认启动此次 Release。
