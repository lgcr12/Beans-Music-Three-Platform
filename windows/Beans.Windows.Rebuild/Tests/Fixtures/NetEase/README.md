# NetEase discovery fixtures

These sanitized fixtures model the public response fields used by the Phase 5C adapter.
They were constructed on 2026-09-20 from the response shapes referenced by
`Beans/NetEaseAPI.swift`; they are not saved user responses and are used only by the
offline test project.

The files intentionally contain no Cookie, authorization token, account profile,
membership data, playback URL, quality key, private playlist, or signing secret.
