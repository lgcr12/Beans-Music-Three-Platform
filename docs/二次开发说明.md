# Beans Music 二次开发说明

## 项目来源

本项目是对 [XIaodou0416/Beans-Music](https://github.com/XIaodou0416/Beans-Music) 的二次开发，不是原项目的官方发行版。二次开发的起始代码为原仓库提交 `3617004`（`chore: bump build to 1.5.5 [skip ci]`）。

原项目与本二次开发均依照 [MIT License](../LICENSE) 发布。原作者的版权声明已完整保留。

## 主要修改

### 三端架构

- Apple 端保留 SwiftUI，目标平台调整为 iOS 26 和 macOS 15 Mac Catalyst。
- 新增 Windows 11 的 .NET 10 + WinUI 3 客户端。
- 新增 ASP.NET Core 10、PostgreSQL、Redis 和 Caddy 构成的可自托管服务端。
- 新增 OpenAPI 接口契约、Docker Compose 配置和三端 CI 构建流程。

### Beans 账号与同步

- 新增邮箱注册、邮箱验证、密码登录、令牌轮换和设备管理。
- 新增设备扫码登录和一次性交换会话。
- 新增端到端加密保险库，用于跨设备同步平台授权和用户数据。
- 新增 SQLite 离线 outbox、增量游标、删除墓碑和冲突合并。
- QQ 音乐和网易云授权不再强制依赖 Beans 账号；不登录 Beans 也可使用当前设备上的平台功能。

### 音乐与播放

- 调整 QQ 音乐登录、会员标识和播放密钥解析。
- QQ 音乐 vkey 请求增加 `qm_keyst` / `qqmusic_key` 等凭证支持，并对多种音质档位进行回落。
- 补充搜索结果的媒体标识、本地音乐、播放历史、收藏统计和播放队列。
- 第三方平台凭证仅保存在 Apple Keychain 或 Windows DPAPI，服务端不代理或保存明文音频地址。

### 界面与交互

- 重新制作应用图标和引导页资产。
- 新增“青碧玻璃”“清透纸感”“午夜霓虹”三套可切换视觉风格。
- 新增 `85%–140%` 全局字号调节，同时保留歌词的独立字号设置。
- 将“我的”重构为“音乐宇宙”，展示当前歌曲、封面墙、收藏与播放统计。
- 新增 iPhone 单栏布局与 Mac/Windows 桌面三栏布局。
