# Windows 两个专区说明

Windows 主线客户端 `windows/Beans.Windows.Rebuild` 把“找音乐”和“找番剧”拆成两个一级专区。它们共用全局播放服务、队列、账号状态、平台缓存和错误处理，但各自拥有独立的信息架构与视觉语言。

## 发现专区

![发现专区 Hero 与内容卡片素材](../windows/Beans.Windows.Rebuild/Assets/Home/hero-mountain-lake.jpg)

发现专区是面向日常听歌的跨平台入口，核心目标是让用户从“平台内容”快速走到“可播放的歌单”。页面不依赖某一个音乐平台的私有首页，而是将 QQ 音乐、网易云音乐的公开发现内容统一为同一组 Windows 卡片和列表组件。

### 页面结构

1. **平台选择与状态栏**：在 QQ 音乐、网易云音乐之间切换；标题、平台徽标、授权提示、刷新按钮和错误提示始终跟随当前平台变化。
2. **Hero 推荐**：展示当前平台的公开精选入口。没有登录平台账号时，页面明确显示公开预览或授权状态，不将预览内容当作个性化推荐。
3. **排行榜**：以横向卡片列展示平台榜单，点击后进入榜单详情或将榜单歌曲加入播放队列。
4. **推荐歌单**：展示平台推荐歌单，卡片包含封面、标题、来源平台和歌曲数量，点击后进入歌单详情。
5. **歌单广场**：按“推荐、流行、华语、欧美、轻音乐”等分类浏览更多公开歌单，并支持横向滚动浏览。

### 数据与可用性

- 在线模式通过 `IMusicDiscoveryService` 和 QQ 音乐 / 网易云适配器加载榜单、推荐歌单与歌单广场。
- 每个平台维护独立的加载状态、缓存和错误信息；切换平台不会把上一个平台的内容误显示在当前平台。
- 网络不可用时优先读取有效缓存；没有缓存时显示明确的离线或公开预览状态，并保留重试入口。
- 歌单详情、搜索结果和推荐卡片使用统一的播放入口，歌曲进入全局队列后由底部播放器继续控制。

## 二次元专区

![二次元专区放送首页 Hero](../windows/Beans.Windows.Rebuild/Assets/Home/Anime/anime-hero-ultrawide-v1.png)

二次元专区是独立的动漫音乐内容空间，围绕“番剧作品 → 主题曲 → 播放器”组织内容。它不是给普通歌单换一套背景，而是提供番剧资料、季度版本关系、主题曲匹配和收藏状态的一整套浏览流程。

### 三个子视图

1. **放送首页**：展示近期/当季番剧、历史上的今天和今日主题曲。每首主题曲显示作品、季度、曲目类型（OP、ED、插曲等）和当前匹配状态；匹配成功时可直接播放，未匹配时进入作品详情继续查找。
2. **番剧索引**：支持中文名、日文名和罗马音搜索，按年份与题材筛选，并可按最新放送、最早放送或作品名称排序。系列页会把前传、续集、番外和不同季度版本归并到同一作品关系中。
3. **我的收藏**：分别保存收藏的番剧和主题曲，支持关键词过滤、取消收藏、打开作品详情和将收藏曲目加入播放队列。

### 从番剧到播放

- 目录数据优先读取本地精选快照，再向 Bangumi 公开接口更新近期放送、搜索和系列关系。
- 每个作品保留中文名、日文名、罗马音、别名、年份、题材、简介、海报、背景图和外部资料链接。
- 主题曲记录会尝试匹配 QQ 音乐与网易云音乐结果，并保存平台、曲目类型、版本和匹配置信度。
- 播放时复用全局 `PlaybackService`，因此二次元专区的主题曲可以和普通歌单歌曲混排、切换歌词和进入队列。

## 两个专区的关系

| 维度 | 发现专区 | 二次元专区 |
| --- | --- | --- |
| 主要对象 | QQ 音乐 / 网易云公开榜单与歌单 | 番剧作品、季度版本与主题曲 |
| 浏览方式 | 平台切换、榜单、推荐、分类歌单 | 放送首页、索引搜索、系列关系、收藏 |
| 数据来源 | 平台发现适配器与本地缓存 | 本地精选快照、Bangumi 公开资料、平台曲目匹配 |
| 播放入口 | 歌单详情、榜单歌曲、搜索结果 | 主题曲匹配、作品详情、收藏曲目 |
| 视觉重点 | 玻璃卡片、平台徽标、横向内容轨道 | 动漫 Hero、作品海报、季节场景与分层动效 |
